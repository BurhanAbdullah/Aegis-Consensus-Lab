# Initial Transactions Audit — tag4

## Current status

This is an initial audit checkpoint, not a final referee report.

### Critical issues to resolve

1. **Manuscript/repository numerical consistency:** existing manuscript governance headline numbers must be regenerated from the current experiment artifacts; prior review identified discrepancies with phase-space/topology summary data.
2. **Trust dynamics:** the manuscript's multidimensional trust/PRC formulation must be reconciled with the implementation's current scalar trust mechanics.
3. **PRC semantics:** explicitly separate changes to trust state from attenuation of governance influence.
4. **Quorum theory:** do not claim classical PBFT/Byzantine quorum guarantees unless a weighted quorum-intersection theorem is actually proved under explicit assumptions.
5. **Recovery theorem:** replace any unsupported iff/survival implication with a theorem that follows directly from a fully specified state recursion.
6. **Stability claims:** establish a real state-transition model and Jacobian/spectral-radius condition, or weaken the claims.
7. **Attack terminology:** distinguish measurement/FDI attacks from actual topology modification.
8. **Experimental protocol:** freeze train/test rules, attack locations, attack magnitudes, seeds, noise/covariance settings, and statistical uncertainty.
9. **Localization:** expand beyond one selected bus per IEEE case and treat slack/reference-bus attacks separately.
10. **Reproducibility:** make code, equations, CSVs, figures, tables, and manuscript values derive from one frozen pipeline.

The rebuilt paper should center on the **security–availability tradeoff induced by predictive trust governance**, with a mathematically derived feasible/stability region that is compared against empirical phase-space results.
